# موقع السهاد للسفر والسياحة

موقع تعريفي من صفحة واحدة، مبني بـ React وCSS حديث (دون مكتبات واجهة إضافية)،
بالعربية (RTL) والإنجليزية (LTR)، وبنمطين نهاري وليلي، مع عرض صور متحرك في الواجهة وتأثيرات مرتبطة بالتمرير.
الإجراء الرئيسي «خطط رحلتك معنا» ينتهي برسالة بريد إلكتروني جاهزة يراجعها الزائر ويرسلها بنفسه.
لا حسابات، ولا دفع، ولا قاعدة بيانات، ولا تخزين لبيانات الزائر.

## التشغيل المحلي

**الطريقة الأسهل:** انقر مرتين على **`start.command`** (أو اكتب `npm start` في الطرفية).
يبني الموقع، ويشغّله كما سيعمل على الاستضافة، ويفتح الموقع ولوحة التحكم في المتصفح:

- الموقع: http://localhost:8080/
- لوحة التحكم: http://localhost:8080/admin/ ← اسم المستخدم `admincp`

للإيقاف: Control + C في نافذة الطرفية. المحتوى المحفوظ والصور المرفوعة محلياً تبقى في مجلد `.local/` بين مرات التشغيل.

لإعادة تعيين كلمة مرور المدير (محلياً أو على الخادم عبر SSH):

```bash
SUHAD_STORAGE=.local php server/tools/create-admin.php admincp كلمة-المرور-الجديدة --force
```

يتطلب Node.js 18 أو أحدث، و PHP 7.4 أو أحدث.

```bash
npm run build      # نسخة النشر كاملة (الموقع + لوحة التحكم + واجهة PHP) في dist/
npm run serve      # تشغيل dist/ الحالية مع PHP على http://localhost:8080
```

للتطوير مع تحديث فوري: شغّل `npm run dev:api` في نافذة، و`npm run dev` في أخرى، ثم افتح http://localhost:5173
(لوحة التحكم على http://localhost:5173/admin/). البيانات المحلية تُحفظ في مجلد `.local/` خارج البناء.

إن لم يكن الأمر `php` متاحاً فاستخدم نسخة XAMPP: `/Applications/XAMPP/xamppfiles/bin/php`.

`npm run build:artifact` يبني نسخة المعاينة لـ Claude Artifacts (الموقع + لوحة تجريبية تحفظ في المتصفح)، وليست مطلوبة للنشر.

## لوحة التحكم

العنوان: **`/admin/`** على نطاق الموقع (مثل `https://alsuhadtours.com/admin/`).

### أول دخول

1. افتح `/admin/`، ستظهر شاشة «إنشاء حساب المدير».
2. أدخل **مفتاح الإعداد** الموجود في `api/_config.php` (القيمة `setup_key`)، ثم اسم المستخدم وكلمة مرور لا تقل عن 10 أحرف.
3. بعد إنشاء الحساب يتوقف عمل المفتاح نهائياً. يُفضَّل تغيير المفتاح في الملف قبل الرفع.

### ما يمكن التحكم فيه

| الصفحة | ما تتحكم فيه |
| --- | --- |
| الأقسام وأماكن الظهور | ترتيب أقسام الصفحة، إظهارها أو إخفاؤها، وتشغيل عناصر الموقع أو إيقافها (زر اللغة، النمط الليلي، الزر الثابت، مسار الطائرة، الحركة…) |
| الواجهة والعرض المتحرك | العنوان والأزرار، صور العرض (إضافة، حذف، ترتيب، إخفاء)، موضع العنصر الرئيسي في كل صورة، التشغيل التلقائي ومدة كل صورة |
| من نحن / خدماتنا / الوجهات | كل النصوص باللغتين، الصور، الأيقونات، ترتيب العناصر وإظهارها، وسم «مقترح» أو «مثال تجريبي»، تفاصيل البرامج |
| دعوة للتواصل / النموذج / التذييل | كل النصوص، ورسائل الأخطاء، وقالب رسالة البريد |
| التواصل والإعدادات العامة | اسم الشركة، النطاق، البريد، واتساب، ساعات العمل، روابط التواصل الاجتماعي، عنوان الصفحة ووصفها وصورة المشاركة |
| نصوص عامة | روابط القائمة، أزرار الترويسة، ونصوص الواجهة الصغيرة |
| مكتبة الصور | رفع الصور (تُنشأ منها مقاسات متعددة تلقائياً)، نقطة التركيز عند القص مع معاينة، مصدر الصورة وترخيصها، الحذف |
| النسخ السابقة | استعادة أي نسخة من آخر 30 حفظاً، أو العودة إلى المحتوى الأصلي |
| الحساب | تغيير كلمة المرور وتسجيل الخروج |

- تعديلات النصوص والترتيب تظهر في الموقع بعد الضغط على **حفظ التغييرات** (أو Ctrl/⌘ + S)، وتُحفظ نسخة احتياطية تلقائياً قبل كل حفظ.
- تعديلات مكتبة الصور (رفع، نقطة تركيز، مصدر، حذف) تُحفظ فوراً.
- إن حفظ شخص آخر نسخة أحدث في الوقت نفسه، تنبّه اللوحة بدل أن تستبدل عمله.

### الحماية

- كلمة المرور تُحفظ مشفّرة (password_hash)، والجلسة تنتهي بعد ساعتين دون نشاط.
- كل طلب يغيّر شيئاً يحمل رمز حماية من الجلسة (CSRF)، وملف تعريف الجلسة `HttpOnly` و`SameSite=Strict`.
- بعد 5 محاولات دخول خاطئة يُقفل الدخول من العنوان نفسه 15 دقيقة.
- الصور المرفوعة يُتحقق من أنها صور فعلاً (JPG أو PNG أو WebP)، وتُعاد معالجتها وتُحفظ بأسماء عشوائية.
- مجلد `data/` ممنوع من التصفح، وبيانات الدخول محفوظة بصيغة لا تُعرض حتى لو طُلبت مباشرة.
- الروابط الخارجية المسموحة تبدأ بـ https:// فقط، والنصوص تُعرض آمنة دون تنفيذ أي شيفرة.

## الرفع على الاستضافة

1. شغّل `npm run build`، ثم ارفع **محتوى** مجلد `dist/` كاملاً إلى جذر الموقع (public_html مثلاً)، بما فيه الملفات المخفية `.htaccess`.
2. تأكد أن الخادم يدعم PHP 7.4 أو أحدث (يُفضَّل أن تكون إضافة GD مفعّلة لإنشاء مقاسات الصور).
3. أول استخدام للوحة ينشئ مجلدَي `data/` و`uploads/` تلقائياً. إن ظهرت رسالة «لا يمكن الكتابة على الخادم»،
   أنشئهما يدوياً واجعل صلاحياتهما قابلة للكتابة (755 أو 775).
4. افتح `/admin/` وأنشئ حساب المدير.

**عند رفع تحديث لاحقاً:** ارفع `dist/` من جديد لكن **لا تحذف ولا تستبدل** `data/` و`uploads/` على الخادم؛ فيهما المحتوى المحفوظ والصور المرفوعة.

**على خوادم Nginx** (دون .htaccess): اجعل `index.php` أول ملف فهرس، وامنع الوصول إلى `/data/` وإلى الملفات التي تبدأ بشرطة سفلية داخل `/api/`.

**إن لم يتوفر PHP:** يعمل `index.html` موقعاً ثابتاً بالمحتوى الافتراضي، لكن دون لوحة تحكم.

## المحتوى الافتراضي (للمطوّر)

بعد تشغيل لوحة التحكم يُدار المحتوى منها. المحتوى الافتراضي الذي يبدأ به الموقع (ويُستعاد بـ«العودة إلى المحتوى الأصلي») في
**`src/content/site.js`**.
كل نص مكتوب باللغتين معاً بالصيغة `{ ar: '…', en: '…' }`، فتُعدَّل الترجمة بجانب الأصل.

| ما تريد تعديله | المفتاح في الملف |
| --- | --- |
| البريد، واتساب (اختياري)، ساعات العمل، روابط التواصل | `contact` |
| النطاق النهائي (يفعّل الرابط الأساسي والبيانات المنظمة) | `company.url` |
| عنوان الصفحة ووصفها وصورة المشاركة | `seo` |
| نصوص الأقسام | `hero`، `about`، `services`، `destinations`، `cta`، `planner`، `footer` |
| صور العرض المتحرك ومدة كل صورة | `hero.slides`، `hero.interval` |
| الصور ومصادرها | `media`، `credits` |

### حالة المحتوى

- `status: 'suggested'` يُظهر وسم «مقترح». غيّرها إلى `'approved'` بعد الاعتماد.
- `sample: true` في الوجهات يُظهر وسم «مثال تجريبي» وملاحظة أعلى القسم. احذفها عند اعتماد وجهات حقيقية.
- `program` في كل وجهة (المدة، يشمل، الشروط) لا يظهر إلا عند تعبئته بمعلومات حقيقية.

### التواصل

- عند إضافة `contact.email` يتفعّل زر «فتح الرسالة في البريد» في النموذج، ويصبح زر «تواصل معنا» الثابت رابط بريد.
  قبل ذلك يعرض الموقع بوضوح أن التواصل «لم يُفعَّل بعد».
- `contact.whatsapp` اختياري؛ عند إضافته يظهر زر «متابعة عبر واتساب» في خطوة المراجعة فقط، ولا يُعرض الرقم نصاً.
- الرسالة تُبنى من القالب `planner.message`. الموقع لا يرسل شيئاً بنفسه، ولا يعرض أي إشعار باستلام الطلب.

### إضافة صورة

من لوحة التحكم: **مكتبة الصور ← اختيار صور**. تُنشأ المقاسات تلقائياً، ثم تختار الصورة في أي حقل صورة.
(للمطوّر: صور التصميم الأصلية في `public/images/` ومسجّلة في `media` داخل `site.js`.)

### اللغتان

- زر اللغة في الترويسة يبدّل بين العربية (RTL) والإنجليزية (LTR) فوراً، ويبقى الزائر عند القسم نفسه وتبقى بيانات النموذج كما هي.
- الرابط `?lang=en` يفتح الإنجليزية مباشرة (للمشاركة)، والاختيار يُحفظ في متصفح الزائر.
- التنسيقات مبنية على خصائص CSS المنطقية (inline-start / inline-end)، فتنعكس تلقائياً مع الاتجاه.
- الاسم الإنجليزي `Al-Suhad Travel & Tourism Ltd.` نقل صوتي مقترح؛ لا يوجد اسم إنجليزي في الشعار. عدّله في `company.name.en` بعد اعتماده.
- لإضافة لغة ثالثة: أضفها إلى `LOCALES` في `src/content/index.js` و`LOCALE_CODES` في `src/content/localize.js`، ثم أضف مفتاحها بجانب كل نص.

### النمط الليلي والنهاري

- يتبع إعداد جهاز الزائر تلقائياً، وزر القمر/الشمس في الترويسة يثبّت اختياره ويحفظه في متصفحه.
- ألوان النمطين أدوار في `src/styles/tokens.css` (سطح، نص، إبراز، زر…)؛ المكوّنات لا تستخدم ألواناً مباشرة.
- في النمط الليلي يوضع الشعار على لوحة فاتحة حتى تبقى ألوانه الأصلية واضحة دون تعديلها.

### العرض المتحرك في الواجهة

- أربع صور تتبدل كل 7 ثوانٍ بتلاشٍ هادئ وتكبير بطيء، مع أزرار السابق/التالي والإيقاف ومؤشر تقدّم لكل صورة.
- يتوقف تلقائياً عند: الضغط على «إيقاف»، أو تركيز لوحة المفاتيح على أزراره، أو خروج الواجهة من الشاشة، أو إخفاء التبويب.
- مع تفضيل «تقليل الحركة» يبدأ متوقفاً ولا يتحرك إلا إن شغّله الزائر.
- تُحمَّل الصورة الأولى فقط عند فتح الصفحة، ثم التالية قبل ظهورها.
- `focus` في كل صورة هو موضع عنصرها الرئيسي (من 0 إلى 1). على الحاسوب تُزاح الصورة ليبقى هذا العنصر بعيداً عن النص في الاتجاهين،
  لذا تناسب العرضَ الصورُ التي يقع عنصرها الرئيسي قرب المنتصف (بين 0.4 و0.6).

### تأثيرات التمرير

- طائرة صغيرة على خط منقّط أسفل الترويسة تتقدم مع التمرير (مؤشر موقعك في الصفحة).
- عمق خفيف: صور الواجهة و«من نحن» والوجهات تتحرك داخل إطاراتها أبطأ من الصفحة.
- ظهور هادئ للعناصر عند دخولها الشاشة.
- كل ذلك يتوقف مع تفضيل «تقليل الحركة»، عدا مؤشر التقدم لأنه يتبع التمرير مباشرة.

## بنية المشروع

```
admin/index.html   صفحة لوحة التحكم
server/
  api/             واجهة PHP: auth, content, media, backups (+ _bootstrap, _config, _image, _render)
  htaccess/        قواعد الحماية التي تُنسخ مع البناء
  dev-router.php   للتشغيل المحلي فقط
scripts/           gen-defaults, postbuild (يُنشئ index.php), build-artifact
src/
  admin/           لوحة التحكم: AdminApp, schema.js (وصف كل الحقول), fields, media, pages, api.js
  content/   site.js (المحتوى باللغتين)، localize.js، index.js (اللغات والسياق)
  components/ Header, Hero, About, Services, Destinations, CtaBand, TripPlanner, SiteFooter, ContactFab, StructuredData
  ui/        Icon, Picture (صور متجاوبة), StatusBadge, SectionHeading
  hooks/     useReveal, useScrollEffects (العمق ومسار الطائرة), useActiveSection, useReducedMotion
  lib/       message.js (بناء الرسالة وروابط mailto/wa.me), text.js, preferences.js (اللغة والنمط), boot.js
  styles/    tokens.css (متغيرات التصميم) + ملف لكل قسم
public/
  brand/     الشعار الأصلي ونسخ مصغّرة منه، والأيقونة المفضلة
  images/    الصور بعروض متعددة (WebP)
```

### ما يُحفظ في متصفح الزائر

تفضيلان فقط: اللغة (`suhad-lang`) والنمط (`suhad-theme`). لا تُحفظ أي بيانات من النموذج أو بيانات شخصية.

المصادر والتراخيص في `CREDITS.md`.
